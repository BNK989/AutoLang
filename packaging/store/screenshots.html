Nothing you type leaves your PC

A tool that sees your keystrokes has to earn trust. These are design rules, and the source code is public so anyone can check them.

  • No account, no analytics, no telemetry.
  • Only the current line is kept, in memory, and dropped on Enter, click or window switch.
  • Password fields are skipped, along with terminals, remote desktops and VMs.
  • The log never contains text, only counts and timings.
  • Free and open source.

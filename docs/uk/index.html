Набрали не тією мовою? Уже виправлено.

AutoLang помічає слова, набрані не в тій розкладці, правильно передруковує їх і перемикає клавіатуру за вас — у будь-якій програмі Windows. Більше жодних Alt+Shift, стирання й повторного набору.

Як це працює

Розкладку клавіатури не видно, аж поки ви не наберете ціле речення абракадабри. AutoLang читає самі слова — так само, як пошуковик розуміє, що ghbdsn мало бути привіт.

01

Усі варіанти одночасно

Кожна натиснута клавіша читається в усіх установлених у вас розкладках, тож слово, яке ви набираєте, існує одразу в усіх ваших алфавітах.

02

Рішення за фразою

Списки слів і невелика мовна модель оцінюють кожен варіант. Очевидні слова виправляються після наступного пробілу; короткі неоднозначні (як-от англійське to / івритське אם) чекають, доки речення не прояснить, що малося на увазі.

03

Виправляє й перемикає

Неправильний текст замінюється, клавіатура перемикається на потрібну мову, а ви просто друкуєте далі. Натисніть Pause, щоб скасувати, — і AutoLang запам’ятає це слово.

Будь-які два алфавіти

AutoLang працює з розкладками, які у вас уже встановлено. Він перемикає між різними алфавітами й не чіпає пари з однаковим алфавітом, як-от англійську й німецьку. Іврит + англійська — найретельніше перевірена пара; решту додано нещодавно.

  • akuo→שלום
  • יקךךם→hello
  • ghbdtn→привет
  • kalhmera→καλημερα
  • lvpfh→مرحبا

Списки слів для англійської та івриту постачаються разом із програмою. Для іншої мови клавіатури AutoLang один раз завантажує її загальнодоступний список слів (це можна вимкнути).

Створено, щоб не заважати

Інструмент, який бачить ваші натискання клавіш, має заслужити довіру. Це закладені в нього правила, а не налаштування.

  • Ніщо не залишає ваш ПК. Жодного облікового запису, аналітики чи телеметрії.
  • Зберігається лише поточний рядок — у пам’яті, і стирається після Enter, клацання чи перемикання вікна.
  • Поля паролів пропускаються, а також менеджери паролів, термінали, віддалені робочі столи й віртуальні машини.
  • Журнал ніколи не містить тексту — лише лічильники й час виконання для усунення неполадок.
  • Скасування однією клавішею. Pause скасовує виправлення; Shift+Pause виправляє примусово.
  • Завжди на видноті. Значок у треї показує, коли AutoLang працює, стоїть на паузі або пропускає вікно.
  • Керування для кожної програми. Вимкніть AutoLang для будь-якої програми або змініть, як він у ній передруковує текст.
  • Відкритий код — тож кожне твердження на цій сторінці можна перевірити.

Встановлення

Windows 10 (1809 або новіша) чи Windows 11, 64-розрядна, з розкладками щонайменше для двох різних алфавітів (Настройки → Час і мова → Мова та регіон). Встановлювати .NET не потрібно.

Портативна версія (найпростіше)

  1. Завантажте AutoLang.exe і покладіть будь-куди, наприклад в окрему папку. Це один файл: нічого не треба розпаковувати чи встановлювати.
  2. Запустіть AutoLang.exe. Попередня версія ще не має цифрового підпису, тож Windows SmartScreen покаже попередження: натисніть More info → Run anyway.
  3. У треї з’явиться зелена A. Клацніть її правою кнопкою миші → Start with Windows, якщо хочете, щоб AutoLang запускався під час входу в систему.

Інсталятор (MSIX)

  1. Завантажте dev-signing.cer і AutoLang-x64.msix.
  2. Один раз додайте тестовий сертифікат до довірених: двічі клацніть файл .cer → Install Certificate… → Local Machine → Place all certificates in the following store → Trusted People → Finish.
  3. Двічі клацніть файл .msix → Install. AutoLang запускається разом із Windows і повністю видаляється через Настройки → Програми.

Версія для Microsoft Store уже на підході. Їй не знадобиться сертифікат, і вона оновлюватиметься сама.

Запитання

Чому антивірус або SmartScreen видають попередження?

AutoLang використовує стандартний механізм перехоплення клавіатури Windows — той самий, що й кейлогери, а попередня збірка ще не має цифрового підпису. Вихідний код відкритий, тож будь-хто може перевірити, що саме робить програма. Якщо Defender помістить її в карантин, відновіть програму й додайте виняток для її папки.

Програма виправила те, чого не слід було виправляти.

Одразу натисніть Pause. Виправлення скасується, і це слово більше ніколи не виправлятиметься. Якщо таке повторюється, будь ласка, повідомте про проблему і вкажіть ці слова.

В одній програмі виправлення виходять спотвореними.

Клацніть у цій програмі, потім клацніть правою кнопкою значок у треї → Typing method (спосіб введення) і спробуйте Simulated keys (імітація натискань) або Paste via clipboard (вставлення через буфер обміну). Вибір запам’ятовується лише для цієї програми.

Чому AutoLang не працює в програмах, запущених від імені адміністратора?

Windows не дозволяє звичайним програмам бачити вікна з підвищеними правами чи вводити в них текст. Там значок стає помаранчевим; усе інше працює як звичайно.

Чи перемикає AutoLang між англійською й німецькою або французькою й іспанською?

Ні. Розкладки зі спільним алфавітом залишаються без змін: більшість слів правильні в обох мовах, а перемикаєтеся між ними ви свідомо. Shift+Pause однаково дає змогу перетворити текст вручну.

Японська, китайська чи корейська?

Не підтримуються. Ці мови вводять через редактор методів введення (IME), який і так виконує перетворення.

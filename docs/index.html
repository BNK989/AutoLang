Typed it in the wrong language? It's already fixed.

AutoLang watches for words typed in the wrong keyboard layout, retypes them correctly and switches the keyboard for you, in any Windows app. No more Alt+Shift, delete, retype.

How it works

The keyboard layout is invisible until you've typed a whole sentence of gibberish. AutoLang reads the words themselves, the way a search engine knows that akuo was meant to be שלום.

01

Every reading at once

Each key you press is read on every keyboard you have installed, so the word you're typing exists in all of your alphabets at the same time.

02

Decides on the phrase

Word lists and a small language model score each reading. Clear words are fixed on the next space; short ambiguous ones (to / אם) wait until the sentence makes it obvious.

03

Fixes and switches

The wrong text is replaced, the keyboard switches to the right language, and you keep typing. Press Pause to undo, and AutoLang remembers that word.

Any two alphabets

AutoLang works with the keyboards you already have installed. It switches between different alphabets and leaves same-alphabet pairs, like English and German, alone. Hebrew + English is the most tested pair; the others are newer.

  • akuo→שלום
  • יקךךם→hello
  • ghbdtn→привет
  • kalhmera→καλημερα
  • lvpfh→مرحبا

English and Hebrew word lists ship with the app. For another keyboard language, AutoLang downloads its public word list once (you can turn this off).

Built to stay out of the way

A tool that sees your keystrokes has to earn trust. These are design rules, not settings.

  • Nothing leaves your PC. No account, no analytics, no telemetry.
  • Only the current line is kept, in memory, and dropped on Enter, click or window switch.
  • Password fields are skipped, along with password managers, terminals, remote desktops and VMs.
  • The log never contains text, only counts and timings for troubleshooting.
  • One-key undo. Pause reverts a correction; Shift+Pause forces one.
  • Always visible. The tray icon shows when it's watching, paused or skipping a window.
  • Per-app control. Disable it for any app, or change how it retypes there.
  • Open source, so you can check every claim on this page.

Install

Windows 10 (1809 or later) or Windows 11, 64-bit, with keyboards for at least two different alphabets (Settings → Time & language → Language & region). No .NET install needed.

Portable (simplest)

  1. Download AutoLang-win-x64.zip and unzip it anywhere. Keep AutoLang.exe and the data folder together.
  2. Run AutoLang.exe. The preview is not code-signed yet, so Windows SmartScreen warns: click More info → Run anyway.
  3. A green A appears in the tray. Right-click it → Start with Windows if you want it at login.

Installer (MSIX)

  1. Download dev-signing.cer and AutoLang-x64.msix.
  2. Trust the test certificate once: double-click the .cer → Install Certificate… → Local Machine → Place all certificates in the following store → Trusted People → Finish.
  3. Double-click the .msix → Install. AutoLang starts with Windows and uninstalls cleanly from Settings → Apps.

A Microsoft Store version is on the way. It will need no certificate and update itself.

Questions

Why does antivirus or SmartScreen complain?

AutoLang uses a standard Windows keyboard hook, which is also what keyloggers use, and the preview build isn't code-signed yet. The source is public so anyone can check what it does. If Defender quarantines it, restore it and add an exclusion for its folder.

It corrected something it shouldn't have.

Press Pause right away. The correction is undone and that word is never corrected again. If it keeps happening, please open an issue with the words.

Corrections come out garbled in one app.

Click into that app, then right-click the tray icon → Typing method, and try Simulated keys or Paste via clipboard. The choice is remembered for that app only.

Why doesn't it work in apps running as administrator?

Windows doesn't let normal apps see or type into elevated windows. The icon turns orange there; everything else keeps working.

Does it switch between English and German, or French and Spanish?

No. Layouts that share an alphabet are left alone, since most words are valid in both and you switch between them on purpose. Shift+Pause still converts text by hand.

Japanese, Chinese or Korean?

Not supported. Those are typed through an input method editor, which already handles conversion.

AutoLang for Mac: tester build

Version 0.5.0 · early test build · 14 October 2026

AutoLang fixes text you typed in the wrong keyboard layout. Type akuo with the English layout active and it becomes שלום, and macOS switches to Hebrew. It lives in the menu bar and has no Dock icon.

Thanks for testing. Before you start:

  • This build is unsigned. macOS will not open it until you run one Terminal command, below.
  • It needs macOS 12 (Monterey) or later.
  • Setup takes about five minutes. Testing takes as long as you like.

1. Download the right zip

Open the Apple menu → About This Mac and look at the second line:

  • Chip: Apple M1, M2, M3, M4… → the Apple silicon download.
  • Processor: Intel… → the Intel download.
Download for Apple silicon Download for Intel

About 30 MB each. Safari may unzip it for you; if it does, you get AutoLang.app in Downloads straight away.

2. Install

  1. Double-click the zip if it is still zipped. You get AutoLang.app.
  2. Drag AutoLang.app into Applications.
  3. Open Terminal (Applications → Utilities), paste these two lines, and press Return: 
    xattr -cr /Applications/AutoLang.app
codesign --force --deep --sign - /Applications/AutoLang.app
    The first line removes the "downloaded from the internet" flag. The second signs the app for this Mac only, because Apple silicon Macs refuse to run unsigned apps at all. Neither asks for a password, and both print nothing when they work (the second may print replacing existing signature, which is fine).
  4. Open AutoLang from Applications. A keyboard icon appears in the menu bar, near the clock.

If macOS still says the app "is damaged" or "can't be opened", the two lines did not run on the copy in Applications. Run them again and check that the path matches where you put the app.

3. Give it permission

AutoLang has to see your keystrokes and retype words, so macOS asks for Accessibility permission.

  1. On the prompt, click Open System Settings. You can also use the menu bar icon → Grant Accessibility permission…
  2. Turn on AutoLang in Privacy & Security → Accessibility.
  3. Within a couple of seconds the menu bar icon changes from ⚠︎ to a keyboard. If it doesn't, quit AutoLang from its menu and open it again.

Some macOS versions also ask for Input Monitoring. If they do, allow that as well.

When you install a newer build, macOS treats it as a different app. Before you open it, go to Accessibility, select AutoLang, remove it with −, then add it again with + (or let the prompt add it). Run the two Terminal lines again too.

4. What to expect, and what to try

You need both an English and a Hebrew keyboard in System Settings → Keyboard → Input Sources. Use the plain "Hebrew" layout, not "Hebrew – QWERTY". The AutoLang menu shows English ⇄ עברית when both are there.

  1. Open TextEdit or Notes.
  2. With the English layout active, type akuo and then a space. It should become שלום and the layout should switch to Hebrew.
  3. With the Hebrew layout active, press the keys h-e-l-l-o and then a space (יקךךם). It should become hello .
  4. Right after a correction, tap Shift twice quickly to undo it. AutoLang remembers that word and leaves it alone from then on.
  5. To convert a word that was not corrected, tap Shift twice before you type the space.

Then use it normally for a while. Good places to try:

  • Chat apps: Messages, WhatsApp, Slack, Telegram.
  • A text field in Safari or Chrome, and a Google Doc.
  • Pressing Enter right after a mistyped word, instead of a space.
  • Typing fast, and mixing English and Hebrew in one sentence.

AutoLang does nothing in password fields. Real words in the layout you are using are left alone, so most of the time you should not notice it at all.

5. Report back

Please send:

  • Your Mac model, chip, and macOS version.
  • What worked, what didn't, and in which apps. A word that was changed when it shouldn't have been (or the other way round) is the most useful thing you can tell me.
  • The log: menu bar icon → Open log folder, then send host.log. It records timing and which app was in front. It never records what you typed.

You can send it however you like, or open an issue on GitHub.

Known rough edges

  • The menu is in English only. The Windows version follows the system language.
  • If the Mac is very busy, macOS may switch AutoLang's keyboard watcher off for a moment. AutoLang turns it straight back on, but a word typed during that moment is not corrected. host.log then shows "timed out".
  • Start at login works on macOS 13 and later. macOS may ask you to approve it in System Settings → General → Login Items.

Uninstall

Quit AutoLang from its menu, then drag it from Applications to the Trash and remove it from Privacy & Security → Accessibility. To remove its settings and logs too, delete these two folders:

rm -rf ~/Library/Application\ Support/AutoLang ~/Library/Logs/AutoLang
